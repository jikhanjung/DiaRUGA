해시가 달랐다. 이름만 봤으면 "그대로다" 로 지나갔을 자리다.

## 코드를 한 줄도 안 고쳤다

도감이 3권에서 15권이 됐는데 굽는 도구는 그대로 돌았다. 156 에서 그렇게 지어
둔 것이 여기서 값을 냈다:

- 색인은 `atlas/*.json` 을 **glob 한다** — 파일을 더하면 도감이 는다
- 쪽은 **디스크를 훑는다**(`scan_pages`). 목록 파일(`atlases.json`)을 믿고 세지
  않으므로 굽다 만 자리가 있으면 그 사실이 드러난다
- 화면 자산(`app.js`·`app.css`)에 **도감 이름이 하나도 안 박혀 있다**

굽는 시간은 쪽 1,665장에 91초(일꾼 10) · zip 19초 · 전부 3분이다.

## 그림 크롭은 안 실었다 (사용자 결정)

논문 도감 항목은 배치마다 `crop_image`(`atlas/<도감>/crops/*.png` 440장 · 21 MB)를
들고 있는데 굽는 도구의 배치 dict 가 그 칸을 안 나른다. **넣지 않기로 했다** —
쪽 이미지가 전부 들어가 도판에서 그림을 볼 수 있고, 크롭까지 실으려면 화면 쪽도
같이 손봐야 한다. 나중에 필요하면 그때 붙인다.

## 쪽이 2,105장인 줄 알았다 — 1,665장이다

## 확인

굽고 나서 세 겹으로 봤다. **파일이 생겼다는 것과 화면이 그것을 문다는 것은
다르다**(156·045 와 같은 줄).

1. **`MANIFEST.json` 의 `missing_placements` 0** — 색인이 짚는 자리가 전부
   꾸러미 안에 있다
2. **권별 대조 18/18** — `atlases.json` 의 `rendered` 와 꾸러미의 JPEG 수를
   권마다 맞춰 봤다. 어긋난 권 없음
3. **헤드리스 크로미움으로 `file://` 을 열었다** — 도감 15 · 항목 2,649 ·
   대조표 4,064건이 붙고, 검색(`Actinocyclus`)이 도감별로 걸리고, 논문 쪽
   (1991 연일층군)과 Schmidt band1 쪽의 이미지가 `naturalWidth` 2,196 으로
   실제로 붙었다. **콘솔 오류 0 · 실패한 요청 0**

## 다시 굽는 법

```bash
python tools/build_offline_atlas.py --version 1.2.0            # 3분
python tools/build_offline_atlas.py --version 1.2.0 --limit 8  # 눌러 볼 때
```

**판을 올려 굽는다** — 같은 판에 덮으면 무엇이 든 사본인지 사람이 못 가른다.
새 판 디렉토리에는 이미 구운 쪽이 없으니 쪽은 전부 다시 굽힌다(`--force` 는
같은 판을 다시 굽을 때만 쓴다). 출처 해시와 git 커밋(`33daac5`)은
`MANIFEST.json` 이 들고 간다.
