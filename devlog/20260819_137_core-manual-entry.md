# 137 — 코어 자료를 사람이 넣는다

2026-08-19 · `sclee` · [P17](20260819_P17_core-profiles.md) 5단계 ·
앞의 것은 [136](20260819_136_profile-into-corelog.md)

규조 개수처럼 **우리가 세는 값**을 지점 화면에서 바로 넣는다. 붙여넣고,
무엇이 일어날지 보고, 저장한다.

## 1. 문이 둘이다

```
POST /loc/<지역>/<지점>/series/          항목의 속성 — 만들기·고치기·지우기
POST /loc/<지역>/<지점>/series/points    점 목록 — 붙여넣기
```

**층이 다른 것을 한 payload 에 싣지 않는다** (116). 이름 한 글자를 고치는 일이
그 항목의 점을 갈아치우는 일이 되면 안 된다. 116 은 완료 표시 하나를 켜는 일이
그 판의 교정을 지우던 사고였고, 같은 모양을 여기서 미리 갈랐다.

**둘 다 POST 전용이다.** 주소를 누르는 것만으로 항목이 지워지면 안 된다.

### 열쇠가 경로에 없다

처음에는 `series/<key>/points` 로 두었다. 그런데 어느 항목에 넣을지는 화면의
`<select>` 가 고른다 — 경로에 두면 **JS 로 `action` 을 갈아 줘야 하고, JS 가
없으면 엉뚱한 항목에 조용히 저장된다.** 본문으로 받으면 그 갈래가 아예 없다.

## 2. 반입 항목에는 못 넣는다

`ops/import_coredata.py` 는 `source='import'` 인 항목을 통째로 갈아치운다.
거기에 손으로 넣으면 **다음 반입에 지워지는데, 그때 조용히 사라지면 왜
없어졌는지 알 길이 없다.** 아예 못 하게 하고 이유를 적는다 —
"xlsx 에서 반입한 항목이라 여기서 못 고칩니다. 원본을 고치고 다시 반입하세요."

화면의 `<select>` 에도 안 나오고(`data.locality_detail` 의 `manual_series`)
**서버가 같은 것을 다시 본다**(`manage_data._manual_series`). 화면에서 막는
것은 막는 것이 아니다.

## 3. 미리 보기와 저장이 같은 파서를 지난다

`manage_data.parse_points` 하나다. 둘로 나누면 **"미리 보기에서는 되는데
저장하면 다르다"** 가 생긴다.

미리 보기가 말하는 것은 넷이다 — 새로 들어오는 점 · 이미 있는 깊이를 덮는 점 ·
갈아치우기를 고르면 사라지는 점 · 못 읽어 버리는 줄과 그 이유. 063 의 지우기
문턱과 같은 줄이다: **"안 됩니다" 만 내면 무엇을 먼저 치워야 하는지 알 수 없다.**

파서 규칙:

- 탭·쉼표·빈칸 아무거나 (엑셀에서 두 칸을 긁으면 탭이다)
- 깊이는 **cm 로 받아 mm 정수로** 든다. 바꾸는 자리를 늘리지 않는다
- 빈 줄과 `#` 로 시작하는 줄은 건너뛴다
- **버린 줄을 몇 행인지와 함께 센다.** 붙여넣기는 머리글이 따라오는 일이 흔하다
- 같은 깊이·같은 값은 한 번만, **다른 값이면 멈춘다** — 반입기(`read_block`)와
  같은 규칙이다. 규칙이 둘이면 파일로 넣은 것과 손으로 넣은 것이 다르게 굴러간다

기본은 **덮어쓰기**다(같은 깊이만 덮고 나머지는 둔다). 갈아치우기는 체크를
따로 해야 하고, 그때 몇 점이 사라지는지 미리 보기가 말한다.

## 4. 넣는 자리는 축과 무관하다 — 시험이 잡았다

처음에는 `.csbox` 를 `{% if axis and series %}` 로 감쌌다. 그런데 **항목을
만들면 점이 0개라 축이 없고, 축이 없으면 넣는 자리가 통째로 안 뜬다** —
첫 점을 넣을 방법이 없다. 새 코어를 세우는 순서가 정확히 그 순서다
(지점을 만들고 → 항목을 만들고 → 점을 넣는다).

**화면으로는 안 보였을 고장이다.** 지금 코어 둘은 반입으로 점이 이미 들어와
있어서 축이 서 있었다. 시험이 잡았다.

## 5. 화면과 서버가 다른 말을 하던 자리 하나

`key` 를 서버가 받아서 소문자로 낮추는데, 폼의 `pattern` 은 대문자를 막고
있었다. 폼이 막고 서버가 받는 상태라 **어느 쪽이 규칙인지 모르게 된다.**
낮추는 쪽을 규칙으로 두고(기계 이름이라 대소문자를 가릴 이유가 없다) 폼을 거기
맞췄다. 시험도 그렇게 고쳤다 — 처음에는 "대문자는 거절한다" 로 짰다가 서버를
읽고 뒤집었다.

```
   먼저 보기        새로 4 · 덮기 0 · 못 읽는 줄 2 (1행: 숫자가 아닙니다)
3) 저장             4점 (2줄은 버렸다)
4) 이어 붙이기      새로 2 · 덮기 1 · 갈아치우면 3 사라짐 → 저장 후 6점
5) 그림             바로 칸에 그려진다
6) 노두             자리가 아예 안 뜬다 (서버도 거절한다)
```
