# 056 — 한 시료에 관찰을 여럿 둔다

2026-08-05. 계획은 `TODOs.md` 의 그 항목이었고, 사용자와 만들면서 정한 것이
설계의 절반이다.

## 무엇을 풀었나

지금까지는 **시료 하나 = 슬라이드 하나**였다. 한 번 관찰해 중복 없는 사진 그룹
하나를 얻는 구조다. 앞으로는 **처리 방법이나 시료 특성을 달리해 같은 시료에서
사진 그룹을 여럿** 만든다 — 산처리한 것과 안 한 것, 체 크기를 달리한 것.

폴더는 시료 이름 뒤에 `(1)`·`(2)` 를 붙여 올리고, 접미사 없는 기존 것은 `0` 이다.

## 폴더는 숫자만 받는다

**슬러그가 URL 이기 때문이다.** `urls.py` 는 `<slug:slug>` 이고 Django 의 slug
변환기는 `[-a-zA-Z0-9_]+` 만 받는다. `(산처리)` 같은 폴더를 받으면 슬러그가
`..._` 로 뭉개져 **서로 다른 관찰이 같은 슬러그로 부딪히고**,
`update_or_create(slug=…)` 라 한쪽이 다른 쪽을 조용히 덮어쓴다.

그래서 **폴더는 숫자만, 뜻은 사람이 화면에서** 적는다(사용자 방침). 폴더도
파일도 안 건드리고 이름표는 DB 에만 남는다 — 이름표를 별도 JSON 으로 빼자는
안도 나왔지만 접었다. `import_json.py` 의 JSON 이 DB 보다 한참 낡아 있는 것이
바로 진실이 두 벌일 때 생기는 일이다.

**트래픽은 안 는다.** 목록·코어 페이지가 이미 `Slide` 행을 통째로 읽고 있어
(`select_related`) 칸이 두 개 더 붙을 뿐이다 — 질의도 요청도 그대로다.

## 괄호가 404 를 내던 것부터 고쳤다

`slide_slug()` 가 폴더명을 `.lower().replace(" ","_")` 만 해서 썼다. 접미사
폴더를 올리면 **그룹핑·합성·검출은 멀쩡히 끝나고 뷰어만 통째로 404** 가 된다.
예외도 경고도 없다.

허용 문자가 아닌 것을 전부 `_` 로 눕히고 연속·양끝을 정리하는 일반 규칙으로
바꿨다. `RS23-GC03 71cm (1)` → `260805_rs23-gc03_71cm_1`.

**기존 슬러그가 한 글자도 안 바뀌는지 먼저 쟀다** — 바뀌면 재반입이 같은
슬라이드를 새 행으로 다시 만든다. 260731·260803 일곱은 그대로다. 260729 셋
(`rs23`·`wap13-gc47_116cm`…)은 어긋나지만 그건 `import_json.py` 가 JSON 파일명
으로 만든 옛 슬러그라 이 변경 전에도 이미 어긋나 있었다.

## 칸이 넷인 이유

    obs_no                 폴더 접미사에서 읽은 자동값. 없으면 0
    obs_label              사람이 적는 뜻 (산처리 · 체 20µm). 10자
    hide_in_list           목록에서 숨긴다
    exclude_from_totals    합계에서 뺀다

**자동값과 사람 값을 가른 이유**는 한 칸이면 폴더에서 다시 읽을 때 사람이 적은
것을 덮기 때문이다. 반입·그룹핑은 `obs_no` 만 `defaults` 에 넣고 `obs_label` 은
건드리지 않는다.

**이름표를 10자로 못 박은 것은 사용자 판단이다.** 처음에 40자로 잡고 배지가
길어지면 CSS 로 잘라 감추게 했는데, "애초에 길게 적을 생각이 아니라서" 라는
말에 짧게 바꿨다. **들어온 뒤 감추는 것보다 못 들어오게 하는 쪽이 낫다** —
감춘 값은 `title` 에만 남아 docx 로 구우면 사라지고, 열 너비를 미는지 아닌지를
매번 눈으로 확인해야 한다. 자르는 CSS 가 통째로 없어졌다.

**숨김과 집계 제외를 둘로 가른 것도 사용자 설계다.** 처음에는 코드가 알아서
"관찰이 겹치면 합계를 비운다" 로 가려 했는데, 어느 관찰이 대표인지는 코드가
정할 수 없다(비교하려고 만든 것이다). 사람이 고르게 하는 쪽이 맞고, **안 보여도
조성에는 들어가야 하는 관찰이 있어서** 한 칸으로는 둘 다 못 한다.

## 합계는 숨김을 안 읽는다

여기가 이번에 제일 오래 고민한 자리다.

- **합계는 `exclude_from_totals` 만 읽는다.** `hide_in_list` 를 읽으면 보기
  토글 한 번에 **같은 자료가 다른 숫자를 낸다**
- 그 대가로 "보이는 줄의 합 ≠ 합계" 가 생긴다. **그것을 화면이 적는다**
  (`n_hidden_in`) — 안 적으면 이유 없는 어긋남으로 보인다

처음에는 `datasets()` 질의에서 숨김을 걸렀는데 그러면 합계가 토글을 따라
흔들린다. 거르는 자리를 `datasets_by_core()` 로 물렸다 — **숫자는 전부로,
보이는 줄은 걸러서** 낸다.

**빈 묶음이 되어도 머리줄을 안 지운다.** 한 코어가 통째로 숨겨졌을 때 머리줄까지
사라지면 그 코어가 이 권역에 없는 것이 되고, 묶음 숫자를 다 더해도 아래 합계와
안 맞는다.

## 색이 주고 기호가 보조다

사용자가 "기호를 뒤에 붙이는 것보다 글자 색을 달리하는 것도 괜찮겠다" 고 했고,
**색을 주로 쓰되 기호를 버리지는 않기로** 했다. 이 목록은 docx 로 구워 NAS 로
나간다 — 색만으로 가르면 흑백 출력·복사본에서 두 상태가 통째로 사라진다.

채널을 둘로 나눠 같은 자리에서 기호가 경쟁하지 않게 했다.

- **숨김 → 줄 전체를 흐리게**(`opacity: .45`) + 이름 옆 `※`
- **집계 제외 → 이름이 아니라 개체 수 숫자 옆에 `*`** + 합계 아래 각주.
  표에서 숫자 옆의 `*` 는 "합계에 안 들어간다" 는 각주 관례라 자리가 이미
  정해져 있다

## 깊이 축에서 겹치던 것

`axis.marks` 가 위치를 `depth_cm / bottom` 하나로만 내서 **같은 깊이면 `pct` 가
글자 그대로 같았다** — 하나가 다른 하나를 완전히 가린다.

**점은 참 깊이에 두고 이름표만 아래로 밀어 쌓는다.** 점까지 밀면 깊이 축이
거짓말을 한다 — 그래서 점은 무리의 첫 줄만 찍고 나머지는 갈고리로 이어 들여
쓴다. 미는 양은 `px` 다(`nudge_px`): 축이 길든 짧든 글줄 높이는 그대로라
`%` 로 밀면 짧은 축에서는 너무 많이, 긴 축에서는 안 밀린다.

## 밟은 것

- **`.propform input { display:block; width:100% }` 이 체크박스까지 잡았다.**
  네모 하나가 줄을 통째로 먹고 옆의 설명이 폭 0 으로 눌려 **글자가 세로로 한 자씩
  흘렀다** — 속성 편집 페이지가 3,464px 이 됐다. `getComputedStyle` 로 재기
  전까지는 스크린샷을 봐야 보였다. CLAUDE.md 의 `.detview .tools` 와 같은 종류다
- **각주를 `tfoot` 에 뒀더니 문장 끝이 잘렸다.** 표가 `.scroll` 안에서 가로로
  넘친다. 밖으로 뺐더니 이번엔 **카드 보기에서 목록 맨 위로 올라왔다** — 표가
  `display:none` 이 되면서 그 자리를 물려받았다. `.dsview` 바깥 맨 끝으로 옮겼다
- **`runserver --noreload` 가 템플릿을 캐시하고 있었다.** 고친 CSS 가 안 먹는 줄
  알고 특이도를 의심했는데 그냥 옛 판을 내보내고 있었다. **고친 것이 실제로 도는지
  부터 확인한다**(CLAUDE.md 에 이미 적혀 있는 것)
- **8099 에 다른 세션의 서버가 7시간째 떠 있었다.** 남의 것이라 안 죽이고 옆
  포트로 갔다
- **`tools/publish_preview.py` 는 같은 날 두 번 올리면 그 폴더를 통째로
  갈아치운다.** 오늘 폴더에 이미 옆 세션 12장이 있어서 그대로 돌렸으면 지워졌다.
  손으로 13~20 을 이어 붙였다
