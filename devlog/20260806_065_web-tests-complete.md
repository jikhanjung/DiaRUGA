## 1. 시험이 살아 있는 고장을 하나 잡았다

7단계의 템플릿 위생 검사가 **첫 실행에서** 걸렸다.

```
AssertionError: '{#' unexpectedly found in ... /d/rs23/g/0/
```

`_shots.html` 둘과 `_detection.html` 하나 — **여러 줄 `{# #}` 주석이 렌더 결과에
그대로 나오고 있었다.** 하필 셋 다 **여는 태그 안**이라 브라우저가 주석 낱말을
엉뚱한 속성으로 읽는 자리였다.

```html
<div class="strip" id="strip-stack"
     {# 어디로 갈지는 화면이 정한다. 검토 화면은 /d/, 검출 화면은 /engine/ 안에
        머문다 — … #}
```

**CLAUDE.md 가 경고해 둔 바로 그것이다** ("Django 의 `{# #}` 는 한 줄짜리
주석이다. 여러 줄이면 화면에 그대로 나온다"). 적어 두고도 못 보고 있었다 —
**예외도 경고도 없고, 화면은 멀쩡해 보인다.** `{% comment %}` 로 고쳤다.

적어 두는 것과 검사가 도는 것은 다르다. 053 이 "제약이 있다는 것과 조회가 그걸
쓴다는 것은 다르다" 였는데, 이번은 문서판이다.

## 2. 실패할 수 없는 시험을 하나 만들었다가 고쳤다

6단계에서 저장 차단을 **통째로 풀어 봤는데** `test_저장이_아예_안_나간다` 가
안 걸렸다. 마스크를 클릭하고 있었는데 **그것은 고르는 일이라 `save()` 를 안
부른다.** 그 시험은 애초에 실패할 수가 없었다.

**실패할 수 없는 시험은 없는 것보다 나쁘다** — 덮은 줄 알게 한다. 실제로
저장을 부르는 조작(고르고 분류 키)으로 바꾸고, **보통 화면에서는 저장이
나간다는 대조군**을 붙였다. 대조군이 없으면 "조작이 원래 저장을 안 부른다" 로
영원히 초록이다.

같은 이유로 좌표 짚는 법도 바꿨다. 처음엔 화면 한가운데를 눌러 봤는데 개체
위에 떨어질지가 운이라, 탈락 펼침판 시험이 한 번 **`skip` 으로 조용히 넘어갔다.**
지금은 `svg` 의 `viewBox` 로 이미지 화소 좌표를 직접 짚는다
(`preserveAspectRatio="none"` 이라 변환이 선형이다).

**이 절의 셋이 같은 이야기다** — 초록은 증거가 아니다. 되살려서 잡히는 것을
보고 나서야 "있다" 고 말할 수 있다.

## 4. 픽스처를 운영 분류표로 맞췄다

`badge` 와 `color` 는 `base.html` 의 CSS 와 짝이다(`.badge.<badge>`). **지어낸
배지를 쓰면 그 대조 시험이 늘 실패하거나 늘 통과하거나 둘 중 하나**가 되어
아무것도 안 본다. 그래서 `factories.CLASSES` 를 운영의 여섯으로 맞췄다.

**옮겨 적은 것이라 방향이 하나다.**

    잡는다    `base.html` 의 CSS 가 지워지거나 색이 바뀌는 것
    못 잡는다  운영 DB 에 분류가 늘었는데 CSS 를 안 더한 것

뒤쪽은 `check_db.py` 의 "4. 분류" 몫이다(운영 DB 를 직접 읽는다).
**둘이 같은 것을 본다고 적으면 안 된다.**
