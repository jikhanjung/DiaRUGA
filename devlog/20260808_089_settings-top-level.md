# 089 — 시스템 설정을 최상위 메뉴로 (`/settings/`, 톱니)

2026-08-08 · 사용자 요청

## 무엇이 문제였나

관리 화면은 **데이터셋 목록의 하위처럼 놓여 있었다.**

- 들어가는 길이 목록 화면 제목 옆의 `관리 →` **하나뿐**이었다
- 화면 머리줄이 `데이터셋 / 관리 · 운영` 이라 **목록에 속한 것**으로 읽혔다
- 그래서 다른 화면(시야 목록·갤러리·계측 표·시야 화면)에서는 **길이 아예 없었다**

그런데 그 화면이 하는 일은 목록의 하위가 아니다 — 층을 만들고 옮기고 지우고,
**뷰어 전체가 무엇을 검토할지**를 정한다. `/manage/` 는 소속을 잃은 관찰을 잡아
주는 **유일한** 화면이기도 하다(063). "길이 없으면 없는 화면이다" 를 적어 놓고
길을 한 자리에만 뒀다.

사용자 방침: **데이터셋 목록과 같은 층의 최상위 메뉴**로 본다.

## 한 일 넷

### 1. 이름 — 관리 → **시스템 설정**

화면 제목·머리줄·다른 화면이 부르는 이름을 전부 바꿨다. 머리줄에서 `데이터셋 /`
breadcrumb 을 뗐다 — 같은 층이므로 앞에 붙을 것이 없다.

```
데이터셋 / 관리 · 운영      →      시스템 설정 · 운영
```

### 2. 주소 — `/manage/` → `/settings/`

**옛 주소는 302 로 살린다.** 사내에 퍼진 링크와 브라우저 기록이 조용히 깨지면
안 된다 — `core/` → `loc/` 와 같은 갈래이고, 301 이 아닌 이유도 같다(브라우저가
캐시하면 나중에 규칙을 다시 손볼 때 되돌릴 방법이 없다).

**쿼리스트링을 그대로 넘긴다.** 저장 뒤 `?msg=…` 로 돌아오는 길이 있어서, 옛
주소를 북마크한 사람이 그 메시지를 잃으면 "저장이 됐나" 를 묻게 된다.

**뷰 함수와 템플릿 파일 이름은 `manage*` 그대로 뒀다.** `settings` 는
`django.conf.settings` 와 부딪히고(이 앱이 그것을 임포트한다), 파일 이름까지
한꺼번에 옮기면 이번 변경이 커진다. **밖으로 나가는 이름**(주소 · URL 이름)만
갈았다. URL 이름은 `settings`·`settings_ops`·`settings_dataset` 이다.

> 이름을 반만 옮기는 것은 원래 안 좋은 습관인데, 여기서는 057 의 교훈이 더
> 무겁다 — **나가는 값을 못 만드는 고장**(`NoReverseMatch`)은 화면 전체를 죽인다.
> 한 번에 옮길 수 있는 만큼만 옮기고, 남은 것을 여기 적어 둔다.

### 3. 길 — 머리줄 오른쪽 끝의 톱니

`base.html` 에 뒀으므로 **어느 화면에서나 같은 자리**다. 목록 제목 옆의
`관리 →` 는 걷었다.

**아이콘을 채운 실루엣으로 그렸다.** 이 앱의 로고가 동심원 + 방사 눈금이라
가는 선으로 그린 기어는 **로고와 구별이 안 된다.** 8개 톱니를 극좌표로 계산해
`fill-rule="evenodd"` 로 가운데를 뚫었다(외부 아이콘 세트를 안 쓰므로 라이선스도
안 딸려 온다).

### 4. 미리보기 — 머리줄에서 시스템 설정의 탭으로

늘 떠 있을 만큼 자주 보는 자리가 아니고, 성격이 "설정·운영 쪽에서 한 번씩 여는
것" 이라 그 탭줄이 제자리다. 다만 **다른 셋과 성격이 둘 다르고 그것을 화면이
말한다**:

- **이 앱의 화면이 아니다** — nginx 가 여는 이웃 자리라 눌러 나가면 탭줄이 아예
  없다. `↗` 를 붙이고 오른쪽 끝으로 밀어 안쪽 셋과 갈라 세웠다
- **없을 수 있다** — `preview_url` 이 비면 탭을 안 낸다. 죽은 탭은 눌러 보고서야 안다

## 밟은 자리 — `only` 가 컨텍스트를 끊는다

미리보기 탭을 넣었는데 **화면에 안 나왔다.** 예외도 경고도 없었다.

```
{% include "viewer/_managenav.html" with here="ops" only %}
```

`only` 가 바깥 컨텍스트를 끊으므로 **컨텍스트 프로세서**(`viewer/context.py`)가
넣어 준 `preview_url` 도 조각 안에서는 안 보인다. `{% if preview_url %}` 가 늘
거짓이 되어 탭이 조용히 사라진다.

`only` 를 뺄 수도 있었지만 그대로 두고 **손으로 넘겼다** — 조각이 무엇을 받는지
호출부에 적혀 있는 편이 낫고, 이 저장소의 다른 include 도 그 규칙이다.
