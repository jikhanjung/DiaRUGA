# 새 칸 하나가 NAS 반입을 막았다 — 그리고 고아 슬라이드를 볼 길이 없었다

**날짜** 2026-08-03
**앞선 문서** `20260803_024_region-and-korea-map.md` (권역), P03 (컨테이너 두 판)

새 자료가 NAS 에 올라왔는데 **반입이 죽고 있었다.** 원인은 내가 이틀 전에 더한
`Site.area` 였다. 함께 드러난 것이 하나 더 있다 — 권역이 안 정해진 슬라이드를
**알리기만 하고 열어 볼 길을 안 만들었다.**

---

## 1. 한 DB 를 판이 다른 두 이미지가 쓴다

```
django.db.utils.IntegrityError: NOT NULL constraint failed: viewer_site.area
[2026-08-03 18:07:03] 반입 실패
```

`Site.area` 를 `default="ant"` 로 더했다. **Django 의 `default` 는 파이썬 쪽이다** —
그 모델을 아는 코드만 값을 붙인다. INSERT 문에는 컬럼이 아예 안 들어간다.

그런데 이 DB 는 **판이 다른 두 이미지가 함께 쓴다.**

```
뷰어        honestjung/diatom:v0.1.16     ← 오늘 여러 번 구웠다. area 를 안다
파이프라인  honestjung/diatom-pipeline:v0.1.0  ← 07-31 이후 안 구웠다. area 를 모른다
```

026 에서 두 이미지의 판을 갈라 둔 것(`PIPELINE_TAG`)이 폴러를 살렸는데, **같은
갈라짐이 이번에는 스키마 스큐를 만들었다.** 판을 갈라 두면 코드도 갈라진다 —
당연한 귀결인데 칼럼을 더할 때 생각하지 못했다.

## 2. `db_default` 로 고쳤다

Django 5.0 부터 `db_default` 가 있다. **DB 자체가 값을 채우므로 옛 코드도 그대로
돈다.**

```python
area = models.CharField(max_length=8, choices=AREA,
                        default="ant", db_default="ant")
```

확인:

```
area 를 안 보내고 INSERT → ('ZZTEST', 'ant')
```

6.92 GB 파이프라인 이미지를 다시 굽지 않고 풀렸다. 굽는 것도 답이지만 **그 답은
다음에 또 스큐가 났을 때 다시 굽게 만든다.** DB 쪽에 두는 편이 오래 간다.

**앞으로 `NOT NULL` 칸을 더할 때는 `db_default` 를 함께 준다.** 두 이미지의 판이
같아질 일이 없기 때문이다 — 뷰어는 화면을 고칠 때마다, 파이프라인은 알고리즘이
바뀔 때만 굽는다.

## 3. 알리기만 하고 갈 곳이 없었다

권역 갈래를 넣으며 이런 안내를 달았다.

> 권역이 정해지지 않은 슬라이드가 1개 있습니다 — 지역(Site)이 붙어 있지 않아
> 어느 탭에도 나오지 않습니다. 속성 편집에서 지역을 지정하면 목록에 들어옵니다.

**"속성 편집" 으로 가려면 그 슬라이드를 목록에서 찾아야 하는데, 목록에 없어서
나온 안내다.** 막다른 길이었다.

실제로 그런 슬라이드가 생겼다 — `260803_bp09-0901`. 폴더명이 `BP09-0901` 이라
`<지역>-<코어> <깊이>cm` 꼴이 아니어서 코어가 안 붙었다.

## 4. `[한국 | 남극 | 전체]`

**`전체` 는 권역이 아니라 "거르지 않는다" 는 뜻이다.** `Site.AREA` 에 넣지 않은
이유가 그것이다 — 슬라이드가 "전체 권역" 에 속할 수는 없다.

그래서 `전체` 는 **지역이 안 붙은 슬라이드까지 담는다.** 그것이 이 탭이 있어야
하는 진짜 이유다.

안내문도 길을 준다.

> … **전체에서 보실 수 있고**, 속성 편집에서 지역을 지정하면 해당 권역 탭에
> 들어옵니다.

`전체` 탭에서는 이 안내가 안 뜬다 — 이미 보이는 것을 또 알릴 이유가 없다.

## 5. `전체` 에는 지도가 없다

**투영이 권역마다 다르다** — 남극 EPSG:3031(극구면), 한국 EPSG:5179(횡메르카토르).
섞인 것을 한 지도에 올릴 수 없다. 억지로 하나를 고르면 다른 권역의 시료가 조용히
빠지거나 엉뚱한 자리에 찍힌다.

버튼도 판도 내보내지 않는다. 026 에서 빈 권역의 보기방식 버튼을 감춘 것과 같은
판단이다 — **눌러도 아무 일이 없는 버튼은 "눌렀는데 안 되네" 로 읽힌다.**

## 확인

```
기본/엉뚱한 값   남극 · 표 9줄 · 지도 있음
한국             표 0줄 · 지도 없음(자료 0)
전체             표 10줄(고아 포함) · 지도 버튼 0 · 지도 판 0
고아 안내        남극 탭에 있고 ?area=all 로 이어짐 · 전체 탭에는 없음
```

반입도 풀렸다. 새 슬라이드 3장이 들어와 파이프라인을 타고 있다.

```
260803_bp09-0901      processing  site=—      프레임 229
260803_gc03-c1_72cm   pending     site=GC03   (새 Site, area='ant' 로 채워짐)
260803_gc03-c1_816cm  pending     site=GC03
```

## 6. 그리고 안내문이 시킨 일이 실제로는 안 됐다

> … 속성 편집에서 지역을 지정하면 해당 권역 탭에 들어옵니다.

`전체` 탭으로 슬라이드를 찾아가 편집 화면을 열어도 **지역을 지정할 수 없었다.**
저장 코드가 이랬다.

```python
if core:  … 코어를 고친다
if site:  … 지역을 고친다
```

**있는 것을 고칠 수는 있어도 없는 것을 만들지는 못한다.** 지역·코어 입력 칸은
빈 값으로 보이는데 무엇을 넣어도 저장되지 않았다.

없으면 만들게 했다. 세 가지를 지킨다.

- **같은 코드가 이미 있으면 그것에 붙인다.** 새로 만들면 unique 로 죽고, 무엇보다
  같은 지역이 둘로 갈라진다. `BP09` 를 새로 만들 수도 있고 `RS23` 에 붙일 수도 있다
- **코드를 안 주면 아무것도 만들지 않는다.** 설명만 고치러 온 사람이 빈 지역을
  만들어 버리면 안 된다
- **새로 만들었으면 그렇게 말한다** — "지역 BP09 · 코어 0901 을(를) 새로 만들어
  붙였습니다."

화면도 고쳤다. 빈 칸만 보이면 "고치는 곳" 으로 읽히지 "만드는 곳" 으로는 안 읽힌다.

> 이 슬라이드에는 **지역이 붙어 있지 않습니다** — 폴더 이름이 `<지역>-<코어>
> <깊이>cm` 꼴이 아니면 파이프라인이 못 붙입니다. 아래에 지역 코드를 넣으면
> 새로 만들어 붙입니다. **이미 있는 코드를 넣으면 그 지역에 붙습니다.**

사본 DB 로 세 경우를 다 확인했다.

```
새로 만들기       Site 4→5 · Core 4→5 · area=kr · region=동해
있는 코드 재사용   Site 5→5 · RS23-GC03 의 pk 그대로
코드 없이 저장     Site 5→5 · 설명만 저장됨
```

**`processing` 중에도 속성 편집은 막히지 않는다.** `review_blocked` 는 검토 저장과
시야 화면에만 걸린다 — 확인해 보고 알았다.
