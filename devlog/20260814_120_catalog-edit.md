# 120 — 카탈로그에서 지우고, 골라서 한 번에 고치고, 묶음을 푼다

2026-08-14 · 작업 · `sclee` · 계획은 [P16](20260814_P16_catalog-edit.md)

P16 의 1~6단계를 다 했다. 계획에서 달라진 것과, **만들면서 잡은 고장 셋**을 적는다.

---

## 1. 무엇이 생겼나

| | 어디에 | 문 |
|---|---|---|
| 지우기·되살리기 | 카드의 `지운다` / `되살린다` | `catalog/save` 에 `act=remove\|restore` |
| 지운 것 보기 | 거르개 `지운 것` 칩 | `?gone=1` → `catalog_rows(gone=True)` |
| 여러 장 한 번에 | 고르면 뜨는 띠 (종명·유형·등급·자세) | `act=bulk` |
| 묶음 풀기 | 카드의 `묶음 N 풀기` | 이미 있던 `/link` 의 `unlink` |

**주소를 안 늘렸다.** 짚는 방식(`(slug, gid)`·이미지 id·`mask_key`)과 막는 검사가
넷 다 똑같아서, 주소로 가르면 같은 검사를 네 벌 적게 된다. 대신 **짚는 규칙을
`_catalog_target` 하나로 모으고** 청소 규칙도 `_catalog_prune` 으로 합쳤다.

**층은 payload 로 갈랐다** (116). 지우기는 `(이미지, 묶음, mask_key)` 에 붙고
동정 다섯은 개체(`DiatomObject`)에 붙는다 — `act` 가 다르면 실리는 것도 다르다.

## 2. 만들면서 잡은 것 셋

### 2.1 지운 화면이 파편을 감췄다 — 카드가 한 장도 안 났다

기본 화면은 파편을 감춘다(2026-08-11). 그 규칙이 `?gone=1` 에도 그대로 걸려서
**파편으로 지운 개체는 되살릴 자리가 없었다.** 살아 있는 교정의 65%가 파편이라
"지웠는데 없다" 가 되는 자리다.

**렌더 결과를 눈으로 보고 잡았다.** 시험은 `catalog_rows(gone=True)` 가 한 줄을
돌려주는 것까지만 보고 있었고 — 그 줄은 실제로 있었다 — 화면이 그것을 거른다는
것은 그 층에서 안 보였다. 086 과 같은 줄이다: **URL 을 덮는 것과 갈래를 덮는
것은 다르다.**

지운 화면에서는 파편을 안 감추고, **파편 체크박스도 안 낸다** — 늘 켜져 있는데
체크박스가 놓이면 눌러서 아무 일도 안 일어나는 자리가 된다.

### 2.2 읽기 전용 시험이 실패할 수 없는 시험이었다

"읽기 전용 화면에 단추가 안 놓인다" 를 세워 놓고 **일부러 단추를 내보게 고쳐도
통과했다.** 시험이 만든 자료가 검토 대상을 다른 묶음으로 옮기는 쪽이라 **카드가
0장이었다** — 없는 카드에서 단추를 못 찾는 것은 당연하다.

자동 처리가 안 끝난 슬라이드(`state="running"`)로 바꿔 세웠다. 이제 카드가 놓이고
읽기 전용이 걸린다. 그리고 시험 첫 줄이 **카드가 있는지부터 본다** — 픽스처가
바뀌어 다시 0장이 되면 그 자리에서 걸린다.

**064 가 적어 둔 그대로다**: 실패할 수 없는 시험은 없는 것보다 나쁘다.

### 2.3 브라우저 시험이 옆 카드의 단추를 보고 지나갔다

되살리기를 누른 뒤 `.catcard .remove` 가 뜨기를 기다렸는데, **옆 카드의 지우기
단추에 곧바로 걸렸다.** 기다린 적이 없는 것과 같아서 그 다음 줄이 경합으로
갈렸다. 기다리는 자리를 `[data-key="…"]` 로 그 카드에 좁혔다.

## 3. 계획에서 달라진 것 — 등급이 붙은 개체를 지울 때

P16 에 없던 갈래다. `ops/check_db.py` 의 **"등급·자세가 살아 있는 개체에만 붙어
있다"** 는 판이 전부 오검출인 개체가 등급을 들고 있는 것을 문제로 센다 — 등급으로
학습 대상을 고르므로 *오검출이면서 A* 는 그대로 자료 선택으로 간다.

지우기를 카드에 붙이면 **그 상태가 쉽게 생긴다.** 갈래 셋을 놓고 골랐다.

| | |
|---|---|
| 지우기를 거절한다 | 오검출을 발견하고도 못 지운다 — 화면이 사실을 막는다 |
| 지우면서 등급·자세를 비운다 | **되돌릴 수 있는 일(삭제)에 되돌릴 수 없는 일을 얹는다** |
| **묻고, 안 비운다** | 무엇이 남는지 말하고 사람이 고른다 ← 골랐다 |

파편으로 바꿀 때 묻는 자리(105)와 같은 모양이지만 **결과가 반대다** — 저쪽은
확인하면 비우고, 이쪽은 확인해도 안 비운다. 파편 지정은 "이것은 완형이 아니다"
라 등급이 **뜻을 잃는** 것이고, 삭제는 되살릴 수 있어 등급이 **다시 쓰일 수
있는** 값이기 때문이다.

## 4. 안 한 것

- **묶기.** 묶음 멤버는 서로 다른 판이어야 하는데(`save_object_link` 가 "같은
  이미지의 멤버가 둘이다" 로 거절한다) 카탈로그는 시야마다 한 판만 카드로 낸다 —
  **묶을 상대가 이 화면에 없다.** 카드마다 판 고르기를 하나씩 다는 일이 된다
- **마스크·경계 고치기.** 폴리곤은 판 전체를 봐야 판단이 서는 자리다
- **일괄 지우기.** 한 번에 여러 장이 사라지는 단추는 누른 뒤에야 범위를 알게 된다
- **106 은 그대로다** — 프레임에만 있는 개체 5,123은 여기서도 못 지운다
