# 038 — Chaetoceros 를 더하다가 나온 것: "표에 넣으면 끝" 이 아니었다

2026-08-04

`ClassDef` 에 `Chaetoceros` 를 Eucampia 와 같은 층(속)으로 더했다. 표를 만든
목적이 **"분류를 더할 때 배포가 필요 없게"** 였으니(models.py 머리말) 행 하나로
끝나야 했다. 그렇지 않았다. 무엇이 남아 있었는지가 이 글의 내용이다.

## 표만으로 따라온 것

행 하나(`0014`)로 이만큼은 저절로 됐다:

- 검출 화면의 **분류 지정 메뉴** — `CLASS_DEFS` 를 순회한다. `is_taxon` 이라
  Eucampia 와 같은 칸(구분선 아래)에 들어갔다
- `/crops/` 의 **형태별 갈래**와 `?cls=chaetoceros` 거르기
- `/review` POST 의 **라벨 검증**(`data.CLASSES`) — 표를 보므로 새 키가 통과된다
- 목록의 **분류 열**과 검출 수 합산 — 037 에서 표가 정하게 바꿔 둔 덕이다

## 따라오지 않은 것 둘

### 1. 색은 아직 CSS 에 박혀 있다

`ClassDef.color` 라는 칸이 있고 `class_list()` 가 그것을 실어 내보내는데,
**아무도 그 값을 쓰지 않는다.** 색은 `base.html` 이 키로 잡는다:

```css
.detview svg.masks polygon.eucampia { fill: rgba(255,110,190,.45); }
```

이런 규칙이 여섯 자리(썸네일 마스크·시야 마스크·크롭 테두리·검출 마스크·
테두리만 그리기·bbox)에 분류마다 하나씩, 그리고 배지 색이 따로 있다.
행만 넣었으면 **Chaetoceros 만 색 없이 그려졌을 것이다** — 마스크가 투명해서
"지정은 되는데 화면에서 안 보이는" 상태가 된다.

지금은 CSS 를 함께 넣어 막았다. 근본은 `--cls` 같은 변수를 표에서 뿜어내고
규칙을 문맥별로 하나씩만 두는 것이다(알파만 자리마다 다르고 RGB 는 분류마다
다르다 — 규칙 30줄이 6줄 + 분류당 한 줄로 줄어든다). **이번에는 안 했다.**
검토 화면의 렌더링을 통째로 건드리는 일이라, 분류 하나 넣는 김에 할 크기가 아니다.

### 2. 검출 화면 머리의 개수 줄

```
후보 5개 (봉상 12, 원형 3, 봉상파편 …, Eucampia …)
```

이 줄의 분류 이름이 템플릿에 손으로 적혀 있었다. Eucampia 를 넣을 때 여기도
같이 고쳤던 자국이 그대로 남아 있다 — **속을 더할 때마다 고쳐야 하는 자리**다.
`data.py` 가 표 순서대로 만들게 바꿨다(`counts_list`). 0 인 분류는 뺀다. 목록
표와 달리 여기는 한 줄이라 자리를 맞출 것이 없고, 짧을수록 읽힌다.

## 색을 무엇으로 골랐나

쓰이는 색을 색상환에 늘어놓으면 이렇다:

```
빨강 0(탈락) · 주황 36(수동) · 노랑 51(선택) · 초록 150(원형) ·
청록 180(원형파편) · 파랑 217(봉상) · 보라 258(봉상파편) · 분홍 325(Eucampia)
```

가장 넓은 빈자리는 **51 → 150 사이**다. 그 한가운데인 90°(연두,
`150,225,75`)로 잡았다. 두 번째 후보는 258 → 325 사이(자주)였는데 폭이 좁아
봉상파편·Eucampia 어느 쪽과도 헷갈릴 자리다.

**색이 여덟이 넘어가면 고르는 것이 아니라 짜내는 일이 된다.** 속을 더 넣을
계획이라면(Identification 트랙) 형태처럼 색으로 가르는 방식 자체를 다시 볼 때다.

## 되돌리기는 지우는 것이 아니라 끄는 것이다

마이그레이션의 역방향이 `active=False` 다. 행을 지우면 그 분류로 붙인 교정이
이름 없는 분류가 되어 화면에서 읽히지 않는다. 꺼 두면 메뉴·집계에서만 빠진다.

## 확인

배포 DB 사본에 0013·0014 를 올리고 테스트 클라이언트로 훑었다.

```
CLASSES    round round_frag rod rod_frag eucampia chaetoceros
TAXON      eucampia chaetoceros
세는 분류   원형 봉상 Eucampia Chaetoceros
200  /  ·  /?area=ant  ·  /d/<슬라이드>/  ·  /crops/  ·  /crops/?cls=chaetoceros
     ·  /d/<슬라이드>/g/0/  ·  /thresholds/  ·  /engine/
후보 5개 (원형 2, 원형 파편 2, 봉상 1, 수동 1, 사람지정 3)   ← 표 순서대로
```

렌더한 인라인 JS 는 `node --check` 통과.
