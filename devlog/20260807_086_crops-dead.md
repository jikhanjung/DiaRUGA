# 086 — 크롭 갤러리와 계측 표가 v0.8.0 내내 죽어 있었다

2026-08-07 · [085](20260807_085_test-instance.md) 를 올리자마자 나왔다

## 무엇이 고장이었나

```
TypeError: _frames() takes 2 positional arguments but 3 were given
```

`_frames` 의 서명이 P09 1단계(`9986bd5`, v0.8.0)에서 바뀌었다:

```python
_frames(vp, det, frame_det_id)   →   _frames(vp, by_path)
```

**"프레임마다 자기 검출을 담는다" 로 뜻이 바뀐 것**이라 옳은 변경이다. 그런데
호출부가 둘인데 하나만 따라왔다. `viewpoint_detail` 은 고쳐졌고
**`candidate_rows` 는 옛 서명 그대로** 남았다.

`candidate_rows` 를 쓰는 화면이 둘이다 — **크롭 갤러리**(`/crops/`)와
**계측 표**(`/detections/`). 둘이 함께 죽었다.

## 왜 슬라이드 전부가 죽었나

터지는 자리는 갈래 안쪽이다:

```python
if st and cur and cur.image and cur.image.kind == "stack":
    ...                          # 합성본 검출 — 안 터진다
else:
    ... _frames(vp, det, ...)    # 프레임 검출 — 여기서 터진다
```

시야마다 갈린다. 그런데 화면 하나가 시야를 **전부** 훑으므로, 프레임 검출로
가는 시야가 **하나라도** 있으면 그 슬라이드 전체가 500 이다. 실제로
**11장 전부** 그랬다.

## 왜 아무도 몰랐나 — 셋이 나란히 비켜 갔다

- **`/healthz` 는 화면을 안 연다.** 057 에서 배운 그대로다 — 링크를 안 만드는
  검사는 링크가 죽은 것을 모른다
- **`smoke.sh` 는 시야 목록 한 장만 연다.** 크롭·계측 표는 목록에 없다
- **시험은 그 URL 을 열었는데도 통과했다.** `test_urls_render.py` 가
  `crops`·`detections` 를 분명히 부르는데, 세운 자료가 **전부 합성본이 있는
  시야**라 `else` 갈래를 한 번도 안 밟았다

셋째가 제일 나쁘다. CLAUDE.md 가 적어 둔 **"실패할 수 없는 시험은 없는 것보다
나쁘다"** 가 정확히 이것이고, 064 에서 한 번 고치고도 다시 났다. **URL 을 덮는
것과 갈래를 덮는 것은 다르다.**

## 고친 것 — `data.py`

`candidate_rows` 가 `viewpoint_detail` 과 **같은 방식으로** `by_path` 를 만든다
(이미지 경로 → `(이미지 pk, 검출 dict)`). 두 화면이 같은 자료를 보게 되는 것이
원래 P09 의 뜻이었다.

덤이 하나 있다. 옛 코드는 프레임 갈래에서 **대표 검출 하나를 프레임 수만큼**
되돌렸다 — 살아 있었더라도 같은 개체가 여러 줄로 나왔을 자리다. 이제 프레임마다
자기 검출을 받는다.

**`_viewpoints_of` 의 프리페치에 `select_related("image")` 를 붙였다.**
`d.image.path` 로 맞추는데 안 붙이면 검출마다 질의가 하나씩 붙고, **시야를 전부
훑는 이 화면에서 그대로 수백 번**이 된다. "개수를 세려고 자료를 물질화하지 말
것" 과 같은 자리다.

## 맞는지 어떻게 봤나

**대조할 옛 출력이 없다** — 운영에서도 500 이라 "예전에는 이렇게 나왔다" 가
없다. 그래서 검토 화면과 앞뒤를 맞췄다:

시야마다 크롭 줄 수가 `_with_reviews` 가 내는 개체 수와 **정확히 같은가**, 그리고
`(stem, key)` 가 중복되지 않는가. 슬라이드 3장 · 시야 150 에서 **어긋난 시야 0 ·
중복 0**. 합성본이 있는 시야는 합성본 것만 세는 것까지 함께 봤다.

렌더는 0.13~0.62초다.

## 시험

`test_urls_render.py` 에 **합성본이 없는 싱글턴 시야** 슬라이드를 세웠다
(`with_stack=False`). factory 에 이미 있던 갈래인데 이 시험이 안 쓰고 있었다.

되살려서 확인했다 — `data.py` 를 원래대로 돌려놓으면 정확히 두 자리가 깨진다:

```
ERROR: … (slug='wap13-gc47_116cm', name='detections')
ERROR: … (slug='wap13-gc47_116cm', name='crops')
```

333개 전부 통과(브라우저 포함 84초).
