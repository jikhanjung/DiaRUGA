# 159 — 묶음이 보는 권역을 못 박는다 (batch_scope.py)

2026-08-26 · 사용자 방침 · 코드는 `3ff4229`(오전) · **기록을 뒤에 붙인다**

## 방침이 먼저 왔다

사용자가 정했다.

> 남극 것은 YOLO 로 학습시키고, 한국 것은 SAM 으로만 본다. 다음 주부터 들어올
> **RS14-GC04** 시료는 **YOLO 4차가 시작될 때 같이 검출**하고, 그 전까지는
> 검출하지 않거나 SAM 으로만 검출했으면 좋겠다.

적어 두려고 폴러를 열어 보니 **가만히 두면 안 지켜지는 자리**였다.

## 1. 폴러에 갈래가 없다

`poll_nas.sh` 는 `batch_plan.py` 가 펴 주는 **조리법이 적힌 묶음마다 새 슬라이드
전부**를 돈다. 슬라이드·권역을 가리는 곳이 **어디에도 없다** — `pending_slides.py`
는 슬러그만 주고 셸은 권역을 모른다.

조리법이 있는 묶음은 둘이었고 검토 대상이 먼저 돈다.

```
◉ yolo-3차   --backend yolo --scale 1.0 --points-per-side 32
             --weights models/11m-v1seg-1280.pt --all-images
  sam2-전수   --backend sam2 --scale 1.0 --points-per-side 48
```

**방침의 앞쪽은 이미 어겨져 있었다.** 08-26 백업 사본에서 센 값이다.

```
kr  BP  sam2-전수  슬라이드 2 · 검출 142
kr  BP  yolo-3차   슬라이드 2 · 검출 467
```

지점 `ant · RS14 · GC04`(core)는 DB 에 이미 서 있고 시료가 0이다 — 자료만
들어오면 그 즉시 `yolo-3차` 가 먼저 돈다.

## 2. 사용자가 ①과 ②를 함께 골랐다

세 갈래를 근거째로 내고 물었다 — ① `yolo-3차` 조리법 걷기(간단하지만 모든 새
슬라이드에 걸린다) ② 권역 갈래를 코드에 넣기 ③ 지점에 "검출 보류" 표시.
**①과 ②를 함께** 하기로 했다: ①이 지금을 막고, ②가 YOLO 4차 때를 막는다.

## 3. ① 조리법을 비웠다 — 되돌릴 값을 먼저 찍는다

`ops/batch_recipe.py` 를 새로 두었다. 관리 화면(`set_recipe`)이 같은 일을
하는데도 CLI 를 둔 것은 **폴러 쪽 작업이 셸에서 나기 때문**이다.

**비우기 전에 조리법을 JSON 한 줄로 낸다.** 회차를 다시 켤 때 가중치 경로를
기억에 의존하지 않기 위해서다(`weights_guessed: true` 가 이미 그 자국이다).

**순서를 바꿨다** — 권역(`areas: ["ant"]`)을 **먼저 적고 나서** 비웠다. 그래야
되돌릴 값에 규칙이 함께 실린다.

## 4. ② 규칙은 `pipeline/batch_scope.py` 하나다

조리법에 `areas` 를 적으면 그 권역만 본다. **없으면 전부 본다** — 옛 묶음은
아무것도 안 바뀐다.

**`segment_diatoms.py` 가 스스로 거부한다.** 폴러에서만 거르면 손으로 부를 때
새고, 셸은 권역을 모른다. 검출을 실제로 내는 자리에 두니 **폴러로 부르든 손으로
부르든 같은 문**이다. GPU 를 돌리기 전에, `runlog.start` 가 실행 행을 만들기도
전에 본다 — 안 돌 일이면 기록도 안 남아야 한다.

**실패가 아니라 건너뛰기다**(0으로 끝낸다). 폴러는 0이 아니면 "검출 실패" 를
적는데, 방침대로 안 돈 것은 실패가 아니다.

**권역을 못 읽으면 거르는 쪽으로 넘어진다.** 소속을 잃은 슬라이드가 실제로 있고
(`check_db` 7번이 세는 상태), 그때 "모르겠으면 통과" 면 **문이 아니다.**

## 5. 빈 목록은 "전부" 가 아니다

`areas: []` 를 "안 적은 것" 과 같이 다루면 **막으려던 것이 그대로 통과한다.**
비어 버린 값이 조용히 관대해지는 자리라 시험으로 박았다.

## 6. 시험 — 무력화해서 잡히는 것을 봤다

`test_batch_scope.py` 아홉. 규칙을 "늘 통과" 로 바꾸니 **넷이 무너졌다**
(적힌 권역만 본다 · 빈 목록 · 권역을 모르면 거른다 · 이유를 말한다).

실제 자료로도 확인했다 — 파이프라인 컨테이너에서 슬라이드 12장의 권역을 읽어
`ant` 열 · `kr` 둘이 나왔고, ant 전용 묶음이면 **BP 둘만 건너뛴다.**

## 7. 나간 자리

`/srv/DiaRUGA/scripts` 는 평평하고 `run()` 이 거기서 부르므로 **이미지를 안 굽고**
`dbsync.sh` 로 나간다. 다만 **새 파일과 고친 파일이 다르다** — `smoke.sh` 의
스크립트 대조는 `/srv` 에 있는 것만 저장소와 견주므로, 새 파일
(`batch_recipe.py`·`batch_scope.py`)은 "다르다" 를 안 만들지만 고친 파일
(`segment_diatoms.py`·`batch_plan.py`)은 **`main` 병합 전에 밀면 계속 경고가
뜬다.** 그래서 앞엣것만 먼저 보내 ①을 걸고, 병합 뒤에 뒤엣것을 보냈다.
