# 041 — 이름을 DiaRUGA 로, 로고를 심다

2026-08-04

`규조류 뷰어` 를 **DiaRUGA** 로 바꿨다. Diatom Refocusing Using Genus-level AI
의 약자다 — **화면에는 풀어 쓰지 않는다.** 이름은 이름으로 서는 편이 낫고,
뜻은 `base.html` 머리글 주석에 남겼다.

바꾼 자리는 11곳: 화면 제목 7 · nginx 안내 페이지 2 · 머리글 · 설정 머리말.
devlog 와 `docs/` 의 지난 기록은 그대로 뒀다 — 그때의 이름이 그때의 기록이다.

## 표기는 `DiaRUGA` 하나다

`Diaruga`·`DIARUGA`·`diaruga` 로 쓰지 않는다. **대문자 자리가 곧 약자의
자리다**(Dia / R·U·G·A) — 뭉개면 이름이 뜻을 잃는다.

지켜야 할 것이 하나 있다: 이 화면에는 `text-transform: uppercase` 가 두 군데
걸려 있다(표 머리 `th`, 카드 항목 `.stat span`). **거기에 이름을 넣으면 CSS 가
`DIARUGA` 로 만든다.** 워드마크에 그 속성을 얹지 말라고 CSS 옆에 적어 뒀다.

## 원본을 그대로 안 쓴 이유 — 워드마크가 `<text>` 다

받은 SVG 의 글자는 이렇게 되어 있다:

```xml
<text font-family="'Montserrat', sans-serif" font-weight="800">DiaRUGA</text>
```

**이 서버에 Montserrat 이 없고, 사내망이라 웹폰트를 받아 올 수도 없다.** 그대로
쓰면 보는 기기마다 다른 글꼴로 나온다 — 로고가 기기마다 달라지는 것은 로고가
아니다. 그래서 **글자는 SVG 에서 빼고 HTML 로 쓴다**(머리글의 `h1`). SVG 에
남긴 것은 규조 마크뿐이다.

색도 원본은 `#7dd3fc` 로 박혀 있었다. 밝은 테마에서 흰 바탕에 옅은 하늘색이면
안 보인다 — `currentColor` 로 바꿔 부모 색을 물려받게 했다.

## 파일이 아니라 심었다

**이 배포에는 정적 파일을 내보내는 길이 없다.** `staticfiles` 가 앱 목록에는
있지만 `STATIC_ROOT` 가 없고 nginx 에도 static 자리가 없다 — 운영(DEBUG=0)에서
정적 파일은 아무도 내주지 않는다. 파일로 두면 그 길부터 뚫어야 한다.

마크는 1 KB 다. `viewer/_logo.html` 로 심는 편이 맞다. 요청도 한 번 줄고,
서브경로(`/diatom/`) 아래에서 경로가 틀어질 일도 없다.

원본 둘(svg·png)은 `docs/assets/logo/` 에 남겼다. 화면이 쓰는 것은 아니고
"이것을 보고 만들었다" 는 근거다.

## 작은 자리에서는 덜어내야 형태가 남는다

마크는 두 겹 테두리 + 방사 늑골 16개다. 작게 줄여도 "규조" 로 읽히는 것이 이
방사 무늬라 머리글(21 px)에서는 개수를 줄이지 않았다. 대신 **선을 원본보다
굵게** 줬다 — 680 폭에 그린 3 짜리 선을 21 px 로 줄이면 사라진다.

**탭 아이콘(16 px)은 늑골을 8개로 줄였다.** 16개를 그대로 두면 뭉개져 회색
원반이 된다. 색도 여기서는 고정이다 — 탭에는 물려받을 색이 없다.

## nginx 안내 페이지는 옮겨 적었다

`maintenance.html`·`unavailable.html` 은 Django 를 거치지 않는다(뷰어가 죽어
있을 때 뜨는 페이지라 그래야 한다). 템플릿을 못 쓰므로 마크를 **그대로 옮겨
적었다.** 로고를 고치면 여기도 같이 고쳐야 한다 — 파일 안에 그렇게 적어 뒀다.

## 확인

전 화면 200, 머리글에 마크와 워드마크가 함께 렌더된다. 다만 **브라우저가 없어
눈으로는 못 본다** — 실제로 렌더한 머리글을 어두운/밝은 테마와 크기별(16·21·
32·64 px)로 모은 미리보기를 따로 만들어 확인받았다.
