# 117 — 동남극 도판집에 색인을 만든다 (P14 4.3)

**뷰어 연동은 아직 막혀 있다** — `web` 컨테이너가 `/nfs/temp-share` 를 못 보고,
그건 `/srv` 를 고쳐야 하는 `paleoadmin` 의 자리다(P14 4.4). 그 자리를 기다리는
동안 **마운트 없이 되는 것**을 했다: P14 4.3 이 남겨 둔 색인이다.

도감 셋 중 **우리 자료와 제일 가까운 것에만 색인이 없었다.** 남극 퇴적물 코어
규조 도판집이고, 거기 나오는 *Fragilariopsis kerguelensis* · *Thalassiosira
lentiginosa* · *Actinocyclus ingens* 는 RS23 이 검토 화면에서 늘 보는 것들이다.

결과: `Diadiction/md/east_antarctic_plates_index.md` — **학명 43개 · 22속 ·
그림 121개** (Plate 1–9 = 107, SEM Figures = 14).

## 1. 자료가 예상과 달랐다 — 텍스트 레이어가 없다

`pdftotext -layout` 이 **20바이트**를 냈다. 쪽 구분자만 있고 글자가 하나도 없다.
`notes/03` 이 Plate별 종 목록만 들고 쪽 번호가 없던 이유가 이것이다 — 앞선 작업도
눈으로 읽어 만든 것이고, 눈으로 읽은 만큼만 남겼다.

그래서 폴더 문서(`notes/04`)가 적어 둔 두 번째 갈래로 갔다: **300 dpi 렌더 →
직접 판독.** 20쪽뿐이라 비싸지 않다.

**먼저 72 dpi 로 20쪽을 한 장에 붙여 구조부터 봤다.** 이게 없었으면 쪽마다
열어 보며 무엇이 어디 있는지 헤맸을 것이다. 구조가 한눈에 갈렸다:

```
설명면 = 홀수 PDF 쪽 (책 72, 74, … 90)
도판면 = 짝수 PDF 쪽 (책 73, 75, … 91)
```

**Schmidt Atlas 와 반대다** — 그쪽은 해설면이 짝수, 도판면이 그다음 홀수다.
색인 표기(`PDF p.N/N+1`)는 같은 모양이라 **표기가 같다고 규칙이 같은 줄 알면
틀린 쪽을 연다.** README 의 "도판 이미지 찾는 법" 에 그 차이를 적어 두었다.

읽을 것은 설명면 10쪽으로 줄었다. 전면을 그대로 읽히면 글자가 작아지므로
**글자 덩어리만 잘라 냈다** — 행·열 잉크 밀도로 본문 블록을 찾고 스캔 그림자와
쪽번호를 떨어냈다. 첫 판은 그림자를 본문으로 집어 백지 한 장을 냈다(문턱 150이
회색 그림자를 잉크로 셌다). 문턱을 100으로 내려 갈렸다.

## 2. 검산을 자료가 스스로 하게 했다

사람이 읽은 것을 사람이 다시 읽어 확인하는 것은 값이 싸지 않고, 같은 자리에서
같이 틀린다. **자료 안에 이미 있는 잉여를 썼다.**

- **시료 코드 ↔ 깊이.** `sec.4-305` 는 문서 열 곳 넘게 나오고 그때마다
  `345.7 cm` 가 붙는다. **코드 36개 중 깊이가 어긋나는 자리가 하나도 없어야 한다.**
- **그림 번호.** Plate 마다 1부터 빠짐없이 이어져야 한다.

둘 다 통과했다(코드 36개 · 어긋남 0 · 그림 빠짐 0). 그리고 **이 검산이 원문의
오류를 드러냈다** — 어긋난 자리를 세는 도구가 곧 원문을 세는 도구였다.

## 3. 원문이 틀린 자리 11건

| 자리 | 원문 | 정정 |
|---|---|---|
| pl.3 | *Thalssiosira* · Makarova**et** | *Thalassiosira* · Makarova et |
| pl.4 | Rattr**y** | Rattr**ay** |
| pl.5 fig.2 | *A. parvulu* | *A. parvulus* |
| pl.6 fig.7·8 | 191.0 **m** · 519.2 **m** | cm |
| pl.6 fig.8 | 저자 **Ehrenberg.** | Karsten |
| pl.8 fig.4 | *naviculo**ies*** | *naviculoides* |
| pl.8 fig.11·12 | `Diploneissp.` · `Delphineissp.` | 띄어쓰기 |
| pl.9 fig.5·7 | `sec.2-145, cm` · `sec.3-177, cm` | **깊이가 통째로 빠졌다** |

단위 `m` 두 건이 오타라는 것은 **다른 항목이 말해 준다** — 같은 코드 `sec.3-169`
가 pl.8 fig.13 에서는 `191.0 cm` 다. 짐작이 아니라 대조다.

**깊이가 빠진 둘은 채우지 않았다.** 값은 안다(다른 항목에서 163.8 · 200.1 cm).
그런데 **그것은 이 도감이 그 그림에 대해 말한 것이 아니다** — 코드가 같으니
같은 시료일 것이라는 내 추론이다. 색인은 빈 채로 두고 근거를 옆에 적었다.
이 저장소가 "자동값이 사람이 채운 것을 덮으면 안 된다" 로 겪은 것과 방향이
같다(063). **읽은 것과 미룬 것을 한 칸에 담으면 나중에 갈라낼 수 없다.**

표제어는 정정한 이름으로 세우고 **원문 표기를 항목마다 함께 적었다.** 인용할
때 쓰라고 "Plate 별 원문" 절을 원문 그대로 따로 두었다 — 폴더 규칙이
"색인 텍스트를 그대로 인용하지 말라" 이므로, 인용할 자리를 아예 갈라 놓는 편이
낫다.

## 4. 곁가지 — SEM 에만 있는 종 하나가 빠져 있었다

`notes/03` 의 알파벳 목록에 ***Fragilariopsis rhombica*** 가 없었다. Plate 1–9
에는 안 나오고 **SEM Figures 에만 있는 종**이라, Plate 를 훑는 방식으로는
놓친다. 42종이라던 것이 43종이다.

이건 105·106 계열의 실수와 같은 모양이다 — **한 갈래만 훑고 전부를 봤다고
말하는 것.** 카탈로그가 프레임 개체를 못 보던 것도, `/crops/` 시험이 합성본
시야만 세워 프레임 갈래를 한 번도 안 지난 것도(086) 같다.

## 5. 색인 말고 무엇이 들어갔나 — 시료 위치

`notes/03` 에 없던 것이 하나 더 있다. 설명면은 그림마다 **구간·깊이**를 달고
있다(`sec.4-305, 345.7 cm`). 종 이름만 뽑았으면 버렸을 칸인데, **우리가 하려는
일에는 이쪽이 더 값지다** — 우리도 시추코어의 깊이별 시료를 본다. 도감의 어느
깊이에서 나온 얼굴인지가 붙어 있으면 나중에 비교가 성립한다.

시료 코드 36개와 깊이의 대응표를 색인 끝에 따로 실었다. 검산에 쓴 것이 그대로
자료가 됐다.

## 6. 고친 자리 — "색인이 없다" 가 네 곳에 적혀 있었다

값을 만들고 규칙을 안 고치면 소용이 없다(113 §3 에서 겪었다). 이번엔 **가리키는
문서**가 그 자리다:

| 자리 | 무엇 |
|---|---|
| `README.md` | 도감 3의 "md 색인이 없습니다" → 색인·규모·주의. `notes/` 목록. **도판 찾는 법에 홀·짝이 Schmidt 와 반대라는 것** |
| `skill/SKILL.md` | `md/` 표에 한 줄. `origin/` 설명. "별도 텍스트 색인이 없다" → 텍스트 레이어가 없다는 것과 원문 오류 주의 |
| `skill/diatom-lookup.skill` | **다시 구웠다** — 꾸러미는 `SKILL.md` 의 사본이라 안 구우면 설치한 쪽이 옛 절차를 따른다(113 §5) |
| `notes/03` | 색인으로 가는 머리말. 알파벳 목록에 *F. rhombica* 보충 |
| `notes/04` | 진행 현황 · 이력 |

확인: 파일 167개 · 비ASCII 이름 0 · 부스러기 0.

**`xls/` 사본은 못 만들었다** — 이 자리에 `openpyxl` 이 없다. 다른 색인 둘은
xlsx 가 있으니 짝이 안 맞는 상태이고, 색인 안에 그렇게 적어 두었다.

## 남은 것

P14 그대로다. **4.3 이 닫혔고 4.4 가 열려 있다** — 뷰어가 이 공유를 못 본다.
`/srv/DiaRUGA/docker-compose.yml` 에 마운트 한 줄(`:ro`)이면 되고 이미지는 안
구워도 된다. 그 뒤에 `atlas.py` 가 이 색인들을 읽는다(P14 3절 갈래 (c)).

**이제 도감 셋이 다 md 색인을 갖는다.** 다만 **형식은 셋이 같지 않다** — 한국
도감은 `**항목번호. *학명***` + `<sub>`, Schmidt 는 `- ***학명*** — Tafel …`
한 줄, 이번 것은 `***학명***` + `<sub>` + 목록이다. 이번 것을 한국 도감 쪽에
맞췄지만 Schmidt 는 항목당 출현이 여럿이라 모양이 다르다.

**그러니 `atlas.py` 는 파서 하나가 아니라 도감마다 하나여야 한다.** 형식을
지금 통일하는 쪽은 택하지 않았다 — 색인은 사람도 읽는 것이고, 파싱하는 쪽이
셋을 아는 편이 값이 싸다. **정할 것은 파서가 아니라 낼 것의 모양이다**(학명 →
도감·자리·시료). 그건 뷰어가 이 공유를 보게 된 다음에 정한다.
